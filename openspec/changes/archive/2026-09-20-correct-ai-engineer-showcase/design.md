## Context

См. proposal.md. Текущие карточки selected-card и i18n уже обеспечивают адаптивность; новые ссылки case-studies.html ещё не опубликованы на домене. Отсюда возможны 404 на публичной версии при локальной доступности файла.

## Goals / Non-Goals

**Goals:** согласовать позиционирование и прямой путь к работающим продуктам.
**Non-Goals:** менять дизайн всего сайта, удалять старые страницы, публиковать изменения.

## Decisions

- Переиспользовать selected-card и существующие обложки. FloatPlayer получает простой локальный графический блок без выдуманного скриншота.
- Ссылки сайтов берутся из опубликованных метаданных проектов/Pages и проверяются HTTP. Не подменять сайт репозиторием под неверной подписью.
- Убрать входящие ссылки на case-studies из основных пользовательских путей, сохранив сам файл для совместимости. Меню ведёт к index.html#products.
- Общий словарь и HTML fallback синхронизируются; PDF пересобираются существующим генератором. Новых runtime dependencies нет.

## Risks / Trade-offs

- Внешний сайт может быть недоступен после проверки: фиксировать дату и фактический статус.
- Старые страницы в кеше: обновить версию i18n и проверить после перезагрузки.
