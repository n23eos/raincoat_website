## Context

См. proposal.md. Третья .prod в #products не имеет обложки; соседние карточки используют .shot. Переводы хранятся в i18n.js.

## Goals / Non-Goals

**Goals:** встроить визуальный стиль Mafia Tool в существующую сетку без новых библиотек.
**Non-Goals:** менять общую сетку и механизм локализации.

## Decisions

- Использовать оригинальную assets/mafia-table-hero-v2.webp с https://mafia-tool.com/, сохранив локально в assets/shots/mafia-tool.webp. Это узнаваемый зелёный игровой стол; генерация новой иллюстрации и скриншот интерфейса не нужны.
- Переиспользовать .shot, .head, .fact, .links. Новые ключи prod.mafia.fact/text в обеих локалях; нейтральный alt «Mafia Tool» с видимым подробным описанием рядом.
- Статус Live и ссылка «Потрогать» через существующий link.try. Не заявлять облачную синхронизацию и видеокомнаты, которых нет на странице продукта.

## Risks / Trade-offs

- [Изображение может обрезаться] → проверить object-fit и композицию на десктопе и 390 px.
- [Описание устареет] → использовать только основные функции, подтверждённые сайтом 2026-09-10.

## Migration Plan

Статические файлы публикуются обычным процессом проекта, публикация не входит в эту задачу. Откат: вернуть карточку и ключи перевода из предыдущей версии, убрать новый WebP.
