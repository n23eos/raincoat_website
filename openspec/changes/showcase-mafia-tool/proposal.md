## Why

Верхняя витрина должна представлять Mafia-tool.com вместо Prompt Manager и давать посетителю понятный путь к работающему продукту.

## What Changes

- Заменить третью карточку в index.html#products: название, описание RU/EN, статус Live и ссылка на https://mafia-tool.com/.
- Добавить локальную оригинальную WebP-обложку с игровым столом с сайта проекта.
- Критерии готовности: обложка загружается, описание переключается RU/EN, ссылка открывает продукт, карточка помещается на мобильном экране.
- Вне объёма: каталог projects.html, бегущая строка проектов, остальные карточки, редизайн сайта и публикация.
