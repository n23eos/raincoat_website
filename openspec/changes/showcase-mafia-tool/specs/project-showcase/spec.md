## Purpose

Верхняя витрина Raincoat знакомит посетителей с работающим помощником по мафии и позволяет перейти к продукту.

## ADDED Requirements

### Requirement: Mafia Tool showcase card
Верхняя витрина SHALL показывать Mafia-tool.com вместо Prompt Manager с обложкой игрового стола, описанием пульта ведущего, записи голосов и проверок и тренировки дедукции, а также ссылкой на https://mafia-tool.com/.

#### Scenario: View and open the project
- **WHEN** посетитель открывает верхнюю витрину главной страницы
- **THEN** третья карточка показывает Mafia-tool.com, загруженную обложку и ссылку на продукт; Prompt Manager в этой витрине отсутствует

### Requirement: Localized responsive card
Карточка SHALL поддерживать RU/EN и сохранять читаемость без горизонтального переполнения на узких экранах.

#### Scenario: Switch language
- **WHEN** посетитель переключает RU на EN и обратно
- **THEN** описание, краткая строка возможностей и текст ссылки отображаются на выбранном языке

#### Scenario: Mobile view
- **WHEN** ширина экрана составляет 390 пикселей
- **THEN** обложка, заголовок, описание и ссылка помещаются в карточке без обрезки текста и горизонтальной прокрутки
