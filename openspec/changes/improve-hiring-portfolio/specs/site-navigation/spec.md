## Purpose

Обеспечить понятную доступную навигацию по портфолио с телефона, клавиатуры и настольного браузера без изменения статической архитектуры.

## ADDED Requirements

### Requirement: Accessible mobile navigation
На всех публичных страницах сайт SHALL предоставлять мобильное меню с переходами к кейсам, странице для команд, блогу и контакту, локализованной кнопкой, состоянием expanded и видимым keyboard focus.

#### Scenario: Open and dismiss menu
- **WHEN** посетитель открывает меню на узком экране
- **THEN** доступны переходы, Escape закрывает меню и возвращает фокус на кнопку, выбор ссылки закрывает меню

### Requirement: Narrow viewport support
Страницы SHALL не создавать горизонтальную прокрутку страницы при ширине от 320 CSS px. Длинные заголовки и ссылки SHALL переноситься внутри контейнеров.

#### Scenario: Read on phone
- **WHEN** посетитель просматривает новые и изменённые страницы на 320 или 390 CSS px
- **THEN** основной контент, кнопки и карточки помещаются в доступную ширину
